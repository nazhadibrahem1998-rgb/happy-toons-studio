# Toon Tennis credits

This match is original code for Happy Toons Studio. It is a side-view game: two round characters with rackets, a ball that travels over a net, and tennis scoring (0, 15, 30, 40, deuce, advantage, first to 3 or 5 games).

## Upstream

No upstream game is included.

A side-view base was required, with a LICENSE file of MIT, BSD, Apache-2.0, zlib, CC0, or Unlicense covering both the code and any assets that would be kept. These public projects were checked and rejected:

| Project | URL | Why it was not used |
| --- | --- | --- |
| phaser_simple_tennis_game by IngkYto | https://github.com/IngkYto/phaser_simple_tennis_game | MIT, but it is vertical Pong (paddles move up and down). It loads Phaser from a CDN and ships audio whose source license is not in the repo. |
| Gravity Pong by Mert | https://github.com/mert574/gravity-pong | MIT, and the license text covers the code. It is a one-paddle keep-up game, not a match with two characters, a net, and tennis scoring. |
| GameZone Tennis | https://github.com/kunjgit/GameZone/tree/main/Games/Tennis | The repo LICENSE is Apache-2.0. The game is vertical Pong, not side-view tennis. |
| tennis-js by Alexey Inkin | https://github.com/alexeyinkin/tennis-js | MIT Pong clone. Not side-view tennis. |
| html5-pong by toivjon | https://github.com/toivjon/html5-pong | MIT Pong. Not side-view tennis. |
| 2D Tennis by YWBK | https://github.com/YWBK/tennis_game | No LICENSE file. It also uses OpenGameArt sounds and Font Awesome. |
| g105b/pong Gravity branch | https://github.com/g105b/pong/tree/Gravity | The notice is not MIT/BSD/Apache. It says modification is free except for teaching. |
| Several “Tennis Game” canvas forks | https://github.com/svrbasky/Tennis-Game-JavaScript | Vertical Pong taken from a paid Udemy course. Not this game’s side-view match. |

Nothing from Nintendo, EA, or other commercial games is used. There is no GPL, AGPL, or LGPL code.
