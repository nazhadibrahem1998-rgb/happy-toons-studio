# ناوی یاری — دیمۆی خۆڕایی

**تاگلاین:** گوندی چیا لە ئیمپراتۆریەتی ئاسن پاک بکەرەوە.

دیمۆیەکی خۆڕاییە. نرخەکەی **٠ دۆلار**ە. بەخشین ئارەزوومەندانەیە، پێویست نییە.

ناونیشانی سەر شاشە «ناوی یاری»ە (ناونیشانێکی کاتی). قارەمانەکە **گڕوت**ە. دوژمنەکە **ئیمپراتۆریەتی ئاسن**ە: هێزێکی خەیاڵی. هیچ وڵاتێکی ڕاستەقینە وەک دوژمن ناو نابرێت و پیشان نادرێت. ئاڵای کوردستان تەنها لای یاریزانە — لە مێنیو، لەسەر خانوو و دارەکانی لای باشووری گوند، و لەسەر جلیقەکەی گڕوت.

## تایبەتمەندییەکان

- تەقەکەری کەسی سێیەم، یەک یاریزان
- ئاستی ١: گوندی چیا
- جوڵان و نیشانکردن و پڕکردنەوەی تفەنگ
- ڕووکاری کوردی سۆرانی، ڕاست بۆ چەپ
- ئاڵای کوردستان بۆ لای یاریزان؛ ئاڵای داڕێژراوی ئیمپراتۆریەتی ئاسن بۆ دوژمن
- سەختی بنەڕەت: ئاسان (ئاسایی لە ڕێکخستنەکان)

# Untitled Kurdish Shooter — Free demo

**Tagline:** Clear a mountain village of the fictional Iron Empire.

This is a **free** demo. Price **$0**. Donations are optional.

The on-screen title is the placeholder **ناوی یاری**. The hero is **Gurut** (گڕوت). The enemy is the **Iron Empire**, a fictional force. No real nation is named or shown as the enemy. The Kurdistan flag is the player's side only: on the main menu, on southern village houses and poles, and as a small patch on Gurut's vest. The occupiers fly an invented Iron Empire banner.

## Features

- Third-person melee, single player, wooden sword (metal sword optional)
- Level 1: a mountain village
- Light combo, heavy attack, block, dodge, soft lock-on
- Touch controls in landscape on phones and mobile browsers
- Sorani Kurdish UI, right to left
- Kurdistan flag for the player; invented Iron Empire banner for the enemy
- Easy difficulty by default (Normal is in Settings)

## Controls

| Action | Binding |
| --- | --- |
| Move | W A S D or arrow keys, or the left stick on touch screens |
| Look | Mouse, or drag on the right side of a touch screen |
| Light attack | Left mouse |
| Heavy attack | F |
| Block | Right mouse (hold) |
| Dodge | Q |
| Soft lock-on | V |
| Jump | Space |
| Pause | Esc |

## System requirements

- Windows 64-bit with a Vulkan GPU, or Android, or a WebGL2 browser
- Phones: landscape. iPhone can use the web build; Godot's web export is single-threaded so it does not need cross-origin isolation headers.

## Notes

Demo: 1 level, placeholder models.

AI-assisted: this demo was made with AI-assisted tools.

Content note: 16+, stylized sword combat, enemies are knocked out, no gore, no guns.
