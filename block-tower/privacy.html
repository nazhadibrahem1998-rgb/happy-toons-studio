Block Tower · بورجی خشت

Privacy

Privacy for this game's optional feedback. Last updated: 31 October 2026.

پاراستنی نهێنی بۆ بۆچوونی ئارەزوومەندانەی ئەم یارییە.

This page is only about Block Tower (بورجی خشت), made by Nazhad Ibrahem at Happy Toons Studio. For the rest of the website, see the studio privacy page.

ئەم پەڕەیە تەنها بۆ یاریی بورجی خشت (Block Tower)ـە، کە نازهاد ئیبراهیم لە Happy Toons Studio دروستی کردووە. بۆ پەڕەکانی تری ماڵپەڕەکە، سیاسەتی گشتیی پاراستنی نهێنی ببینە.

Who it is for

The game is made for teens aged 15–18. We do not ask your age, date of birth, name, or for an account. You never have to give information in order to play. English is the default language. Kurdish (Sorani) is optional.

یارییەکە بۆ گەنجانی ١٥–١٨ ساڵ دروستکراوە. تەمەن، ڕێکەوتی لەدایکبوون، ناو، یان هەژمار ناناسین. هیچ کاتێک ناچاری ناکەین زانیاری بدەیت بۆ ئەوەی یاری بکەیت. زمانی بنەڕەت ئینگلیزییە و کوردی ئارەزوومەندانەیە.

What stays on your device

Best time, highest floor, language, quality, avatar colour, and any queued feedback stay in this browser's localStorage. They are not sent to us. You can clear them in your browser settings.

باشترین کات، بەرزترین نهۆم، زمان، کوالێتی، ڕەنگی یاریزان و ڕیزبەندیی بۆچوونەکان تەنها لە localStorage ـی ئەم وێبگەڕەدا دەمێننەوە. بۆ ئێمە نانێردرێن. دەتوانیت لە ڕێکخستنی وێبگەڕەکەت بیسڕیتەوە.

Feedback

Sending feedback is optional and anonymous. There is no reward, no colour unlock, and no request for a store review. Feedback is not shown in public and there is no chat.

ناردنی بۆچوون ئارەزوومەندانەیە و بێناوە. پاداشت، کردنەوەی ڕەنگ، یان داواکاری پێداچوونەوەی هیچ فرۆشگایەک نییە. بۆچوونەکان بڵاو ناکرێنەوە و گفتوگۆ نییە.

If you send it, we collect only: a rating from 1 to 5, text up to 500 characters, the game version, and a coarse time (the hour, not the second). We do not ask for a name, email, phone, location, account, device id, or fingerprint. Before sending, the game strips emails, phone numbers, links, and long strings of digits.

ئەگەر بینێریت، تەنها ئەمانە کۆدەکرێنەوە: نمرەیەک لە ١ تا ٥، دەقێک تا ٥٠٠ پیت، وەشانی یارییەکە، و کاتێکی گشتی (کاژێر، نەک چرکە). ناو، ئیمەیڵ، تەلەفۆن، شوێن، هەژمار، ناسنامەی ئامێر یان پەنجەمۆر ناناسین. پێش ناردن، یارییەکە ئیمەیڵ، ژمارەی تەلەفۆن، بەستەر و ڕیزبەندیی درێژی ژمارەکان لادەبات.

Why: only to improve the game.

بۆچی: تەنها بۆ باشترکردنی یارییەکە.

How long: about 12 months, then it is deleted. Sending is not switched on yet, so no feedback is sent to a server. It stays on your device, and the game says it was saved to send later.

تا کەی: نزیکەی ١٢ مانگ، پاشان دەسڕدرێتەوە. ئێستا ناردن چالاک نییە، بۆیە هیچ بۆچوونێک بۆ سێرڤەر نانێردرێت.

We do not log your IP address. If sending is switched on later, the Cloudflare Worker writes only those four fields and deletes them after about 12 months. Rate limiting is done without storing IP addresses.

ئێمە ناونیشانی IP ـت تۆمار ناکەین. کاتێک ناردن دواتر چالاک بکرێت، وۆرکەری Cloudflare تەنها ئەو چوار خانەیە لە خەزنەدا دەنووسێت و دوای نزیکەی ١٢ مانگ خۆی دەیسڕێتەوە. سنووری خێرایی بەبێ هەڵگرتنی IP ئەنجام دەدرێت.

What we do not collect

  • No ads, analytics, tracking, cookies, or advertising ids.
  • ڕیکلام، شیکاری، شوێنکەوتن، کووکی، یان پێناسەی ڕیکلام نییە.
  • No social logins or embedded social widgets. Following us is not required to play.
  • چوونەژوورەوەی تۆڕە کۆمەڵایەتییەکان یان ویجێتیان نییە. بەدواداچوون پێویست نییە بۆ یاریکردن.

Hosting

The game is hosted on GitHub Pages. Like any host, GitHub may process technical data such as IP addresses to deliver and protect the site. We do not ask them to keep extra logs. See GitHub's Privacy Statement.

یارییەکە لە GitHub Pages دابەش دەکرێت. وەک هەر خانەخوێیەک، GitHub لەوانەیە زانیاریی تەکنیکی وەک IP بەکاربهێنێت بۆ گەیاندن و پاراستنی ماڵپەڕەکە. ئێمە داوای تۆماری زیادە ناکەین.

Your choices

You can choose not to send feedback. You can clear this site's data in your browser. To ask for deletion or to ask a question, email hello@happytoonsstudio.com. Because feedback is anonymous, tell us roughly when you sent it and what it said so we can find it.

دەتوانیت بۆچوون نەنێریت. دەتوانیت داتای ماڵپەڕەکە لە وێبگەڕەکەت بسڕیتەوە. بۆ سڕینەوە یان پرسیار، ئیمەیڵ بنێرە بۆ hello@happytoonsstudio.com.

Parents and carers can use the same email address. The game is built with the ICO Children's Code in mind: high privacy by default, no nudge to hand over data, and no profiling.

دایک و باوکیش دەتوانن بە هەمان ئیمەیڵ پەیوەندی بکەن. یارییەکە بە لەبەرچاوگرتنی یاسای منداڵانی ICO دروستکراوە: نهێنی بەرز بە بنەڕەت، بێ پاڵنەر بۆ دانی زانیاری، و بێ پرۆفایل.
