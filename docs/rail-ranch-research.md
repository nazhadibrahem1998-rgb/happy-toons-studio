# Rail Ranch research note

Mechanics below were studied, then reimplemented from scratch in Rail Ranch. No code, art, audio, or names were copied. Licenses are the project licenses at the time of this note; we did not use those codebases.

| Game | License | Mechanic we took as inspiration |
| --- | --- | --- |
| OpenTTD | GPL-2.0 | Tile rail building beside an existing line, and hauling goods from producers to a drop-off. |
| Simutrans | Artistic License | Industries that turn one cargo into another, with transport as the link between them. |
| Mindustry | GPL-3.0 | Grid placement with a valid/invalid ghost, and chained processors that only run when inputs are in storage. |
| OpenRCT2 | GPL-3.0 | A build menu, ghost preview, and research-style level gates before new structures appear. |
| OpenLoco | MIT | Paying the player when a consist delivers a load, plus buying extra wagons. |
| Bloodrizer Kitten Game | MIT | Storage caps that stall production, building costs, and a simple XP ladder. |
| Trimps | GPL-3.0 | Short timed jobs with a cash reward, so there is always a near-term target. |
| A Dark Room | MIT | A daily return bonus and a short list of next purchases so progress stays obvious. |

Proprietary games (including the Klondike Adventures ad) were used only as a visual reference for the original toon scene. They are not sources for code or mechanics.
